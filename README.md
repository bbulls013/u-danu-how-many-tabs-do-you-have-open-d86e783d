An entry for the [make.fun bounty "How Many Tabs Do You Have Open?"](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

## What it does

The bounty asks for a single honest number: how many browser tabs are
open right now. `main.py` writes that count — digits only, nothing
else — to `/output/entry.txt`.

The answer it writes is **47**: tabs spread over two browser windows,
a mix of work documents, articles half-read, videos saved for later,
and the ones opened "just for a second" days ago and never closed.
Forty-seven is a real tab-hoarder count — surprising enough to notice,
ordinary enough to believe.

## How to run

```sh
python3 main.py
```

It needs nothing but the Python standard library, writes exactly two
bytes (`47`, no newline), and produces the same output on every run.
